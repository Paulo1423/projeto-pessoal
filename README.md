# 🎮 RPG de Seleção de Raças em Java

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema simples de RPG utilizando a linguagem **Java**, com foco na prática dos fundamentos da programação orientada a objetos (POO).

A proposta inicial é desenvolver um sistema de seleção de raças, no qual cada raça possui atributos próprios, como força, defesa, velocidade e inteligência. Os valores dos atributos são definidos previamente pelo desenvolvedor, enquanto o jogador poderá visualizar as características disponíveis antes de escolher seu personagem.

O projeto está sendo desenvolvido gradualmente, com o objetivo de consolidar conhecimentos de programação e boas práticas de organização de código.

## 🎯 Objetivos

- Praticar os fundamentos da programação orientada a objetos.
- Compreender a criação e a utilização de classes e objetos.
- Trabalhar com atributos e construtores.
- Organizar o código em diferentes classes, separando responsabilidades.
- Desenvolver um menu de seleção de raças.
- Aprimorar a lógica de programação e a estruturação de sistemas em Java.

## ⚙️ Tecnologias utilizadas

- **Java** — linguagem de programação.
- **IntelliJ IDEA** — ambiente de desenvolvimento integrado (IDE).
- **Git e GitHub** — controle de versão e gerenciamento do repositório.

## 🧩 Estrutura planejada

| Classe | Responsabilidade |
|---|---|
| `Raca` | Definir os atributos e o construtor das raças. |
| `Status` | Organizar os objetos e os atributos predefinidos de cada raça. |
| `Main` | Executar o programa e gerenciar o menu de seleção. |

A estrutura poderá ser adaptada conforme o projeto evoluir.

## 🚧 Status do projeto

**Em desenvolvimento.**

O projeto está em sua fase inicial, com foco na criação das classes, instanciação de objetos e organização da estrutura básica do sistema.

Novas funcionalidades serão implementadas conforme o avanço dos estudos.

O desenvolvimento será realizado por etapas, priorizando a compreensão da lógica e dos fundamentos por trás de cada implementação.
